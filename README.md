# 🛍️ **eBazzar Backend**

eBazzar Backend is the server-side component of the eBazzar application, built using Spring Boot. It provides RESTful APIs to manage users, products, and orders for the eBazzar platform.

## 🎯 **Features**

### 🔐 **User Authentication**

- Secure login and registration system powered by JWT tokens.
- Protect your API endpoints with robust authentication mechanisms.

### 🛒 **Product Management**

- Add, update, delete, and fetch products effortlessly.
- Built with scalability and performance in mind.

### 📦 **Order Management**

- Easy-to-use endpoints for placing, viewing, and managing orders.
- Perfect for handling small or large-scale order flows.

### 👑 **Admin Panel**

- Manage users, products, and orders through powerful admin APIs.
- Streamline administrative tasks with full control at your fingertips.

---

## 🛠️ **Technologies Used**

- **🌱 Spring Boot**: A powerful backend framework for building robust REST APIs.
- **🔒 Spring Security**: Ensures secure authentication and authorization using JWT.
- **📂 Spring Data JPA**: Simplifies database interaction with intuitive data access layers.
- **🐬 MySQL**: A reliable relational database, Dockerized for seamless setup.
- **🐳 Docker**: Containerization for MySQL, ensuring consistent environments.
- **⚙️ Maven**: Manages dependencies and builds the project efficiently.

---

## ⚙️ **Setup and Installation**

Follow the instructions below to set up the backend locally with Dockerized MySQL.

### 🛠️ **Prerequisites**

- **JDK 17** or later
- **Docker** and **Docker Compose**
- **Maven**

### 📝 **Installation Steps**

1. **Clone the repository**:

   ```bash
   git clone https://github.com/sajid-777/eBazzar.git

   ```

2. **Make Sure You have Docker Installed in Your Machine**:
   ```bash
   docker compose up
   ```
3. **Navigate to URL**:
   ```bash
   http://localhost:8080/swagger-ui/index.html
   ```

Let me know if you need adjustments! 😊
